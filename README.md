# Wake-Easy
An integrated hardware-software project to create a music player and alarm clock that is controllable through a desktop app.

## How to Contribute
Create a fork of the repository, then clone your fork!

Install Node.JS, then run this command
### Install Frontend Dependencies
```bash
cd frontend
npm install
```

### Install Hardware Dependencies
In VSCode, install the PlatformIO extension.
Then, click the home button and add the `hardware` folder.

## Tech Stack
Frontend: Electron + React 
Hardware: Using C++ with PlatformIO's VSCode extension
Hardware components: ESP32
